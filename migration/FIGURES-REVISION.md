## 示例与技术依据

- 星比对输入为 S1=ACGT、S2=AGT、S3=ACGTT。全局比对匹配 +2、错配 −1、每个空位 −2（含末端）。两两最优得分 4、6、2，总分 10、6、8，按得分最大化选 S1。本例不是对中心星近似比保证的证明，也未将最终多序列排列宣称为全局最优。
- 展示的两组排列是 `ACGT / A-GT` 与 `ACGT- / ACGTT`。第二组存在并列最优排列，正文明确选择其中一种。最终 `ACGT- / A-GT- / ACGTT` 各行等长，去空位可恢复输入；对已有两行同步插入末端空位。
- 仿射示例沿用正文 `g_o+(k-1)g_e` 约定，匹配 2、开启 3、延伸 1；总匹配分均为 6，罚分分别为 4 和 6。依据沿用正文的 [Gotoh 原始论文](https://doi.org/10.1016/0022-2836(82)90398-9) 和既有双序列修订记录；本轮不更改评分模型或重新宣称软件性能。
- POA 图表示与前驱比较依据 [Lee、Grasso、Sharlow（2002）原始论文](https://doi.org/10.1093/bioinformatics/18.3.452) 及 [abPOA 官方实现](https://github.com/yangao07/abPOA/blob/main/src/abpoa_align_simd.c)。本轮实际阅读官方代码中 `lg_backtrack` 的匹配、删除、插入分支：匹配来自各前驱的上一序列位置，删除来自各前驱的当前位置，插入来自当前图节点的上一序列位置。获取时文件 Git blob 为 `af6ff9d321e4a5c986718edad584c89b791d56b4`。原论文页面可读取，全文 PDF 未在本轮取得；具体三类依赖以官方源码及独立计算交叉核对，不将摘要当作完整公式证据。
- 图 6 限定线性空位罚分，取查询第 3 个字符 G。图中 D(v,j) 是以 v 结束的图路径与查询前 j 个字符的最优全局得分；只画内部依赖，不冒充包含边界初始化的完整算法。完整路径为 CAT、CTGT，当前 T₂ 有 A、G 两个前驱，两个 T 用不同编号区分。

## 维护与复现

`scripts/generate-figures.mjs` 集中保存样式、序列、评分、图拓扑与绘图函数。SVG 仅含可编辑文字和基础矢量形状，没有截图、外部字体、脚本或新的网站运行依赖。白色背景在暗色主题下保持不变；颜色同时配合标签，避免单凭颜色解释含义。

```bash
npm run figures    # 修改生成器之后重新生成全部七图
npm run check      # 验证文档，以及 SVG 与生成器的一致性
npm test           # 独立算例校验及既有回归
npm run build      # 检查全部生成网页、链接、锚点和资源
npm run preview
node scripts/figure-qa.mjs
```

浏览器检查使用已有 Playwright 开发依赖，支持 `QA_CHROME`、`QA_URL`、`QA_OUTPUT_DIR`。图片本身通过普通 Markdown 引用。`collect-assets.mjs` 会跳过 `generated` 资源，不会用历史 PNG 覆盖 SVG。改变例子后，须同时修改相关正文、图注、替代文字和测试，并更新 `assets.json` 的大小及描述。
