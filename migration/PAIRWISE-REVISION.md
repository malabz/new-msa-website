| 采用形式 | 首次说明与旧稿处理 |
| --- | --- |

## 核实来源与边界

- [Needleman–Wunsch（1970）原文](https://web.stanford.edu/class/sbio228/public/readings/Bioinformatics_I_Lecture6/Needleman_Wunsch_JMB_70_Global_alignment.pdf)：全局比对的历史来源。教学递推采用现代线性罚分形式，不声称逐字复现原文算法。
- [Smith–Waterman（1981）作者提供的原文](https://dornsife.usc.edu/msw/wp-content/uploads/sites/236/2023/09/msw-042.pdf)：局部矩阵中的零值、最大值起点及回溯终止。
- [Biopython 官方说明](https://biopython.org/docs/latest/Tutorial/chapter_pairwise.html)：替换评分、末端罚分、仿射约定；不依赖某个软件版本的默认参数。
- [Gotoh（1982）文献信息](https://pubmed.ncbi.nlm.nih.gov/7166760/)：作者、年份、题名和 DOI 已核实。原文镜像本次无法取得，不把镜像读取失败写为论文失效；具体递推与边界交叉参考下一项并独立计算。
- [Myers–Miller（1988）原文](https://www.cs.ucf.edu/courses/cap5510/fall2009/SeqAlign/Linear_Space_Alignment.pdf)：仿射模型、边界、空间与路径恢复。原文采用总分与空位状态，本文使用明确的三个末列状态，转换后以穷举核对。
- [Hirschberg（1975）作者提供的原文](https://ics.uci.edu/~dhirschb/pubs/p341-hirschberg.pdf)：前后缀分割、边界、时间与空间分析。
- [Gibrat（2018）原文](https://link.springer.com/article/10.1186/s12859-018-2228-9)：带内路径和带宽的限制；不沿用其年代相关测序误差数字或“唯一精确算法”等宽泛陈述。
- [minimap2 官方算法说明](https://github.com/lh3/minimap2#algorithm-overview)：种子、链、区域比对的分工及遗漏风险。
- [Gribskov 等（1987）原文](https://doc.aporc.org/attach/Course001Papers/gribshovetal1987.pdf)：从已有比对提取位置特异性信息及序列–profile 比较。正文短例为本轮自拟，不是原文数据。
- [FORAlign 官方仓库](https://github.com/malabz/FORAlign)：论文信息、研究入口和开发接口参数性质。没有复现其基准性能。

图片来源沿用 `assets.json`，本轮未更改图片内容；原始出处之外的更早来源和授权信息尚未独立确认。

## 验收结果

- `tests/pairwise-tutorial.test.mjs`：直接读取正文的算例与矩阵，检查各行等长、去空位恢复输入、手算得分和回溯步。
- 以 A/C 字母表生成长度 0–3 的 15 条序列，三组评分下共 675 个有序序列对。独立枚举完整比对并逐列/逐空位段计分，与三状态 DP 对照；其中 225 对同时核对线性 DP。覆盖空序列、完全匹配、错配、连续空位及高错配罚分下的反向空位切换，全部通过。
- `npm test`：8 项测试通过，包括原有导航、部署与发布测试。部署/发布测试只使用本地临时目录。
- `npm run build`：17 个 Markdown 页面检查通过；42 个生成 HTML 的资源、链接、锚点与公式检查通过。构建有单个资源块超过 500 kB 的提示，不影响构建；本轮不扩大到打包优化。
- Chrome 实际加载 1440px、390px 页面，检查公式错误、坏图、页面溢出、明暗切换和搜索；控制台及资源响应无错误。桌面公式与表格、手机正文和暗色主题已查看截图。
- 浏览器逐个打开 `/psa.html#旧id`，原 11 个 id 均跳转到对应正文位置。搜索“仿射空位罚分”可找到新文章。
