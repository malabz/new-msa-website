6. 外链检查结果见 `external-links.json`：`not-found` 表示此次请求返回 404/410 且已进行有限 GET 复核；`restricted` 表示认证、反爬或限流；`unverified` 表示网络、服务端或其他异常。后两类不判定为链接失效。原文中的 FTP 地址只保留，未通过 HTTP 审计验证。
