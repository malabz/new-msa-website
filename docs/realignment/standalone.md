# 独立重比对工具

## 纵向分割方法 {#vertical}

Cut the input sequences into substrings, and once these shorter substrings are realigned, they stitch their alignments together.

### [1. Refin-Align (2019)](https://informatica.si/index.php/informatica/article/view/2621/0) 

In each iteration:
1. Extract the blocks from the  initial alignment based on the columns with the same bases.
1. Delete all gaps in each block and realign it with Promalign.
1. Calculate the SP score of the initial block and the new block.
1. If the score of the new one is higher than the initial, the new block will be the input of the next iteration.

Until no longer improve the SP score of each block. 
- Test data: Protein (BALIBASE, PREFAB, OXBENCH, HOMSTRAD)
- The source code is not publicized.

### [2. SpliVert (2020)](https://www.ingentaconnect.com/content/ben/ppl/2020/00000027/00000004/art00007)

1. Split the initial alignment vertically into 3 parts.
1. Remove the gap characters in the middle part and realign it alone.
1. Splice the realigned middle parts with the other two initial pieces to obtain a realigned alignment.

- Test data: Protein (BALIBASE, OXBENCH, SABmark)
- We did not find the source code.

### [3. RPfam (2022)](https://www.worldscientific.com/doi/epdf/10.1142/S0219720022400029)

RPfam employs the Simulated Annealing algorithm in iteration.

In each iteration:
1. Scan the current MSA for badly aligned blocks and compute score of the blocks.
1. Randomly pick a badly aligned block.
1. Seek the worst aligned fragment in the block.
1. Realign the fragment utilizing DP algorithm.
1. Update the current MSA.

Until the temperature is down to the setting value the iteration ends.
- Test data: Protein (PFAM)
- The source code is not publicized.

## 横向分割方法 {#horizontal}

Split an alignment into groups of whole sequences, which are then merged together by realigning between groups, possibly using each group’s induced subalignment.

### [1. ReAligner (1997)](https://dl.acm.org/doi/pdf/10.1145/267521.267524)

In each iteration has a traversal of all sequence:
1. Pick a sequence
1. Realign the sequence with the profile constructed with the remaining sequences.
1. If the new alignment's quality is improved, the new one will replace the old one.

Until the alignment score saturates to a stable value.
- Test data: DNA/RNA 
- [The source code link is unavailable.](ftp://ftp.cs.arizona.edu/realigner)

### [2. Remove First method (2005)](https://academic.oup.com/bioinformatics/article/21/8/1408/249176)

In each iteration:
1. Randomly pick a sequence.
1. Realign the sequence with the profile constructed with the remaining sequences.
1. Update the alignment if the accuracy improved.

Until the score converges or the reach the limit of iterations.
- Test data: Protein (HOMSTRAD)
- [Source code](http://www.bioinf.ucd.ie/people/iain/iteration.html)

### [3. TreeRefiner (2005)](https://ieeexplore.ieee.org/abstract/document/1498013)

This realigner is based on three-dimensional alignment rather than using an iterative approach.
- Test data: Nucleotide sequences that were generated by the Rose program
- [TreeRefiner's homepage](http://treerefiner.stanford.edu/index.html)

### [4. REFINER (2006)](https://academic.oup.com/nar/article/34/9/2598/2401672)

This realigner is similar to RF method but aims to realign the sequences with the family block models representing conserved sequence/structure regions.

In each iteration:
1. Randomly pick a sequence.
1. Realign the sequence with the PSSM constructed with the remaining sequences.
1. Update the alignment.

Until the alignment score saturates to a stable value or until the iteration cycle terminates.
- Test data: Protein ([CDD](http://www.ncbi.nlm.nih.gov/Structure/cdd/cdd.shtml) and PFAM)
- [FTP server](ftp://ftp.ncbi.nih.gov/pub/REFINER)

### [5. ReformAlign (2014)](https://link.springer.com/article/10.1186/1471-2105-15-265)

In each iteration:
1. Build a profile from the initial alignment.
1. All sequences realign with the profile to obtain the reformed alignment. (There has a profile fine-tuning model.)
1. The alignment with better quality will be the input of next iteration.

 Until the alignment between two successive runs remains unchanged or a predefined maximum number of iterations is reached.
- Test data: DNA/RNA (BRAliBase 2.1 RNA alignment database and DNA SMART database)
- [ReformAlign's homepage](http://evol.bio.lmu.de/_statgen/software/reformalign/)

## 横纵组合方法 {#combined}

### [1. RASCAL (2003)](https://academic.oup.com/bioinformatics/article-abstract/19/9/1155/285019)

The alignment is initially divided **horizontally and vertically** to identify well-aligned, reliable regions. Potential alignment errors are detected by comparing statistical models of the reliable regions. RASCAL then performs a single realignment of each badly aligned region using an algorithm similar to that implemented in ClustalW.

Partitioning steps:
1. The alignment is divided horizontally into sequence subfamilies using Secator
1. Then the alignment is divided vertically into 'core block' regions that are reliably aligned in the majority of the sequences.

These global core blocks are determined using the mean distance column scores implemented in the NorMD OF. Local core block regions are also determined for each subfamily individually, using the same method as for the complete family.
- Test data: Protein (BALIBASE, ProDom)
- [The source code link is unavailable.](ftp://ftp-igbmc.u-strasbg.fr/pub/RASCAL)

### [2. Crumble and Prune (2011)](https://bmcbioinformatics.biomedcentral.com/articles/10.1186/1471-2105-12-144#Sec3)

&#91;vertical&#93; **Crumble** deals with problems that are large in sequence length. It breaks up long alignment problems into shorter problems. 

&#91;horizontal&#93; **Prune** handles problems with a large number of sequences. It cuts up deep alignment problems into sub-problems with fewer sequences. 

**Job-tree** combine Crumble and Prune to align long and deep sequences.
- Test data: human genome, Rfam 
- [The source code link is unavailable.](http://hgwdev.cse.ucsc.edu/~krish/crumble_prune/)
